# Polices de la charte

- **Inter** (titres secondaires, texte, boutons) : chargée depuis Google Fonts (licence libre OFL), graisses 300 et 700.
- **Tiempos Headline** (titres, graisse 300 : la plus fine achetée est Regular) : police payante de Klim Type Foundry.
  La licence web de l'université couvre le domaine **univ-catholille.fr** ; ce dépôt est public, donc les fichiers
  ne doivent pas y être publiés. Déposer `tiempos-headline-regular.woff2` et `tiempos-headline-regular-italic.woff2`
  dans `fonts/tiempos/` (dossier ignoré par git) sur le serveur qui héberge le campus, si la licence le couvre.
  Sans ces fichiers, les titres s'affichent en Georgia.
